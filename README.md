# Кейс № 3. Приветствие на Django

## Техническое задание

1. Главная страница содержит форму с полем «Имя» и кнопкой `Submit`.
2. Модель `Greeting` содержит одно объявленное поле `name` длиной до 100 символов. Django автоматически создаёт первичный ключ `id`. Имена хранятся в SQLite.
3. После валидной отправки приложение сохраняет имя и показывает «Привет, Имя!» на главной странице. Обновление страницы повторно имя не сохраняет. Приветствие относится к текущей сессии браузера.
4. Пустое имя и имя из одних пробелов возвращают ошибку формы. Слишком длинное имя отклоняется сервером без записи в базу.
5. CSS оформляет страницу, форму, поле и кнопку. POST-форма защищена штатным CSRF middleware Django и тегом `{% csrf_token %}`. Шаблон экранирует имя при выводе.

## Запуск

Python 3.10 или новее. Из папки кейса выполните команды в активированном виртуальном окружении.

```sh
python -m pip install "Django>=5.2,<5.3"
python manage.py migrate
python manage.py runserver
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Введите «Анна» и нажмите `Submit`. На главной странице появится «Привет, Анна!». При отправке пустой формы появится «Введите имя.».

Проект настроен для локального запуска. При старте секретный ключ берётся из переменной `DJANGO_SECRET_KEY` или генерируется заново. Записи SQLite сохраняются после перезапуска. Чтобы браузер сохранял приветствие между перезапусками, задайте постоянный секретный ключ в окружении.
